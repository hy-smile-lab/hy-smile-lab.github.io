# 공유드라이브 자동 반영 안내

6시간마다(또는 GitHub Actions 탭에서 수동 실행 시) 공유드라이브의 자료를 읽어 홈페이지에 반영함.

## 드라이브 폴더 구조

```
홈페이지 자료/                         ← 이 폴더를 서비스 계정에 '뷰어'로 공유
├─ 통합 실적 관리자료_YYYYMMDD.xlsx    ← 가장 최근 수정본 사용 (엑셀 양식·시트 이름 유지)
└─ 사진 앨범/
   ├─ 국제 행사/
   │  └─ 2026-05-20 2026 TRB 참석/    ← '날짜 제목' 형식, 안에 사진(jpg·png)
   ├─ 국내 행사/
   ├─ 졸업/
   └─ 연구실 행사/
```

- 실적: 엑셀을 고쳐 다시 올리면 논문·과제·특허·수상·학술대회·저서가 갱신됨. 기존에 홈페이지에서 보강한 논문 링크는 제목이 같으면 유지됨.
- 홈페이지에서 숨길 실적, 엑셀에 없는 실적 추가는 `public/overrides.json`에서 관리.
- 사진: 앨범 폴더를 추가·수정·삭제하면 사진 앨범에 반영됨. 사진은 이름순으로 표시되고 첫 사진이 대표 사진.
- 분류 폴더 이름은 위 네 가지 중 하나로 해야 해당 탭에 표시됨.

## 최초 1회 설정

1. Google Cloud Console(console.cloud.google.com)에서 프로젝트 생성
2. 'API 및 서비스 → 라이브러리'에서 **Google Drive API** 사용 설정
3. 'IAM 및 관리자 → 서비스 계정'에서 서비스 계정 생성 → '키' 탭 → 키 추가 → JSON 다운로드
4. 공유드라이브의 '홈페이지 자료' 폴더를 서비스 계정 이메일(…@….iam.gserviceaccount.com)에 **뷰어**로 공유
5. GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret
   - `GDRIVE_SA_KEY` : 다운로드한 JSON 파일 내용 전체
   - `DRIVE_FOLDER_ID` : 폴더 주소 `drive.google.com/drive/folders/여기부분`
6. Actions 탭 → Deploy to GitHub Pages → Run workflow 로 첫 동기화 확인
